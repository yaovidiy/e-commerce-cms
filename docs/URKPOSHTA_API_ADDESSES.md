1. Пошук індексу для доставки до відділення
Розглянемо випадок, коли відправлення необхідно доставити до одного з
відділень м. Бровари*.
*З 2020 року місто Бровари – адмін. центр Броварського району. Проте за
класифікатором КОАТУУ Бровари – місто обласного підпорядкування.

Пошук відділення виконується у наступному порядку:
Область -> Район -> Населений пункт -> Відділення
Примітка. Область та район необхідно вказувати обов’язково, оскільки назва
населеного пункту може збігатися з іншим населеним пунктом у сусідньому
районі або області, або навіть в межах одного району (докладніше див. приклад
у Додатку 1).
Отримати перелік всіх відділень у населеному пункті можливо двома шляхами:
за ідентифікатором населеного пункту (CITY_ID)
або за кодом KOATUU (KATOTTG)

Крок 1. Пошук області

Знайдемо інформацію про область.
Для адресного класифікатору URI (докладніше див. документацію до адресного
класифікатору):
https://ukrposhta.ua/address-classifier-ws/

справ).

активні записи (відкриті відділення) мають LOCK_CODE = 0.

можуть виконувати доставку з типом ..2W (склад), якщо отримувач є працівником
цієї закритої установи або працівником Укрпошти у цьому відділенні. Відділення
закритого типу можливо відфільтрувати за полем IS_SECURITY = 1 (у звичайного
відділення IS_SECURITY = 0).

2. Пошук індексу для доставки кур’єром

W2D або D2D, потрібно визначити індекс зони доставки, за яким обслуговується
ця адреса (поле postcode у запиті створення адреси).

Область -> Район -> Населений пункт -> Вулиця -> Будинок

населеного пункту може збігатися з іншим населеним пунктом у сусідньому
районі або області, або навіть в межах одного району (докладніше див. приклад
у Додатку 1).

У Львівській області є одразу 5 населених пунктів з назвою с. Лісове. При чому,
одразу 3 з них розташовані у Буському районі, проте всі три належать різним
сільрадам (поле OWNOF): Топорів, Заводське та Тур’я.
Кожний населений пункт має різний CITY_ID. Це необхідно враховувати в процесі
пошуку адреси чи відділення.
Примітка. Населені пункти в одному районі з однаковою назвою можуть
відрізнятися за типом. Наприклад, м. Бар та с. Бар Барського району, Вінницької
області. У цьому випадку необхідно враховувати тип населеного пункту під час
пошуку (CITYTYPE_UA).
